# Release Notes — v1.0.0

Release date: 2026-06-03

Summary
-------

v1.0.0 is the first public release of GemChat. It provides a modern chat experience powered by Firebase AI and Gemini Flash, including persistent chat history and a modular codebase suitable for extension.

Highlights
----------

- Real-time text chat using Gemini Flash (via Firebase AI)
- Local chat history stored with Room
- Jetpack Compose UI with responsive layouts for phones and tablets
- Multi-module project layout for easier maintenance and testing

Breaking changes
----------------

This is the initial release; there are no breaking changes relative to a prior public release.

Upgrade notes
-------------

No migration is required for this initial release. After upgrading, ensure your `google-services.json` is present and matches your Firebase project settings.
